部标 808/1078 协议接入网关 · 架构图

定位是协议接入网关,不是业务系统:对下承接 JT/T 808/1078 终端,对上以 裸流 + WebCodecs 服务播放端,以 API 与 MQ 把 73 类协议消息投递给业务系统。 默认单进程、零外部依赖启动;Redis、RocketMQ、JWT 鉴权与业务系统对接均为可选增强。

信令 / 控制流(信令面) 音视频码流(媒体面) 可选能力,默认降级为零依赖实现 共享状态读写(默认内存,可选 Redis)
